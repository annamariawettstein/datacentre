◈ ABOUT

UK Data Centre Grid

A map of the UK's data-centre planning pipeline, and the argument underneath it: how much probability-weighted power demand is queued up, and where the grid can't meet it.

Two artefacts share one data spine. The map plots every distinct data-centre scheme in the planning system, coloured by status. The gap figure (in progress) weights each scheme by its probability of actually being built, sums the megawatts per Grid Supply Point, and compares that to published network headroom. Survival-weighting is what separates a defensible gap from a raw-queue press release.

◈ METHODOLOGY

How the numbers are made

1 · Data spine

A national keyword sweep of PlanIt pulls every planning application mentioning a data centre (and near-synonyms) into Postgres/PostGIS, logging first_seen per record. High recall by design — the noise is removed next.

2 · Classification

An LLM pass over each description separates genuine data centres from false positives (solar schemes that merely mention them, telecoms cabinets, generic warehousing) and catches sites filed under generic B8 industrial use.

3 · Deduplication to sites

One data centre generates many applications — the original consent, condition discharges, amendments. We collapse them into distinct schemes (one site, one row) via connected-components linkage over shared postcode, ≤180 m proximity, explicit parent/child references, and shared address. Doing the dedupe ourselves, and reporting both counts, is the point.

4 · Scale audit — which ones count

"Data centre" spans a 200 MW hyperscale campus and a hospital server cupboard. A second LLM pass categorises every confirmed site — hyperscale, colocation, enterprise, edge/telecom, ancillary — and we remove telecom exchanges, ancillary server rooms and outright false positives. That leaves — genuine data centres, of which — are power-material — the set the gap figure is built from, not "anything containing the words data centre".

5 · Outcomes & timing

On the Full/Outline subset, outright refusal runs ~2.5% — UK data centres rarely get refused; they get withdrawn or stall. Median time from validation to consent is — days, and roughly half breach the council's own statutory target.

6 · Lapsed consents — a corrected claim

Permissions that have expired look like dead schemes, but "expired" overstates it. Classifying each by later site activity, most were superseded, implemented, or re-applied. Only — sites went fully silent after their permission lapsed — an upper bound on abandoned consents, since a scheme can be built to its original consent with no further applications. We publish the smaller number, not the raw count.

Caveats

— sites carry coordinates and appear on the map; the rest lack any location in PlanIt. Council-portal data is scraped and imperfect. The survival probability and capacity figures are not yet built — this is the data spine, honestly labelled.
